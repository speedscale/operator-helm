  Speedscale cloud in exchange for the API key, so a chart cannot compute it.
  Neither the forwarder nor the replay coordinator will become ready until ALL
  FIVE are supplied -- a partial set counts as none, because the identity is
  considered resolved only when the stream and every root-tenant field are
  non-empty. S-12914 owns how a namespaced install resolves this; until then,
  set them explicitly, together:

    helm upgrade {{ .Release.Name }} -n {{ .Release.Namespace }} \
      --set tenant.id=... --set tenant.name=... --set tenant.bucket=... \
      --set tenant.region=... --set tenant.stream=...
