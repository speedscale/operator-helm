{{- if not .Values.tenant.id }}

WARNING: tenant.id is empty.

  Tenant identity (id / name / bucket / region / stream) is issued by the
  Speedscale cloud in exchange for the API key, so a chart cannot compute it.
  The forwarder will not become ready until it is supplied. S-12914 owns how a
  namespaced install resolves this; until then, set it explicitly:

    helm upgrade {{ .Release.Name }} -n {{ .Release.Namespace }} \
      --set tenant.id=... --set tenant.name=... --set tenant.bucket=... \
      --set tenant.region=... --set tenant.stream=...
{{- end }}

API key:
  This chart does NOT create the API key Secret. It expects
  {{ include "speedscale.apiKeySecretName" . }} to already exist in
  {{ .Release.Namespace }} with keys SPEEDSCALE_API_KEY and SPEEDSCALE_APP_URL.

  kubectl -n {{ .Release.Namespace }} create secret generic {{ include "speedscale.apiKeySecretName" . }} \
    --from-literal=SPEEDSCALE_API_KEY=<your-key> \
    --from-literal=SPEEDSCALE_APP_URL={{ .Values.appUrl }}
